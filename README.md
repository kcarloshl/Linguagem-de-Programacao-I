
# Linguagem de Programação I

Repositório acadêmico da disciplina de Linguagem de Programação I,
do curso de Bacharelado em Sistemas de Informação.

## Sobre a disciplina

A disciplina aborda o desenvolvimento de aplicações utilizando
Java, com ênfase na Programação Orientada a Objetos (POO), na
organização e reutilização de código, no desenvolvimento de
interfaces gráficas e na integração com bancos de dados.

## Linguagem e tecnologias

- Java
- Java Swing
- Banco de dados
- JDBC (quando aplicável)

## Conteúdos estudados

### Programação Orientada a Objetos (POO)
- Classes e objetos
- Herança
- Composição
- Polimorfismo
- Interfaces

### Interfaces Gráficas
- Desenvolvimento de interfaces com Java Swing

### Padrões de Projeto
- Padrões de projeto
- Factory Method

### Banco de Dados
- Conexão entre aplicações Java e bancos de dados

## Organização do repositório

O repositório reúne exercícios, práticas e projetos desenvolvidos
durante a disciplina, permitindo consultar os códigos e revisar
os conceitos estudados.

## Objetivo

Documentar minha evolução no desenvolvimento de software,
consolidar os conhecimentos em Java e Programação Orientada a
Objetos e manter um histórico dos projetos acadêmicos.
